# Technical Plan: Redesign & Modernize Video Download Tab UI (NovaCut Dark Pro)

## 1. Problem Statement & Objectives
- **Context:** The "Tải Video" (Download) tab currently provides single video download and Douyin channel batch download features, but the UI layout has grown organically with inline styles, flat cards, and somewhat cluttered toolbars.
- **Goal:** Redesign the entire Download tab interface to be stunning, highly ergonomic, and 100% harmonious with NovaCut's overall Dark Glassmorphic & Neon Accent design language.

## 2. Key UI/UX Architecture & Improvements

### A. Sub-tab Navigation (Segmented Pill Switcher)
- Transform the sub-tab switchers (`🎬 Tải 1 Video Đơn Lẻ` vs `📺 Tải Toàn Bộ Kênh Douyin`) into a modern iOS/macOS-style **Glassmorphic Segmented Control**:
  - Dark slate pill container (`background: rgba(15, 23, 42, 0.7); backdrop-filter: blur(12px); border: 1px solid rgba(51, 65, 85, 0.6)`).
  - Active indicator with subtle cyan/purple gradient border, glowing glow shadow, and responsive transitions.
  - Distinct badge `PRO BATCH` with animated gradient.

### B. Hero Input & Action Card
- **Single Video Mode:** Hero card with platform icons pill tray (Douyin, TikTok, YouTube, Facebook, Bilibili), auto-clean paste button, and a gradient CTA button (`Phân tích Video`).
- **Channel Mode:** Hero input with URL / sec_uid input, quantity selector (`10, 30, 50, 100, Tất cả`), quick login button `🔑 Đăng Nhập Douyin` with helper tooltip, and prominent `Quét Danh Sách Video` CTA.

### C. Douyin Creator Showcase Banner
- Redesigned banner with creator avatar (gradient border), Verified badge, creator stats counter cards (Followers, Total Likes, Works count), clickable copy/profile link, and crisp bio text.

### D. Pro Batch Action & Filter Toolbar
- **Level 1 (Batch Execution):** Sleek select-all switch, "Đã chọn X/Y video" counter pill, subfolder checkbox toggle, and highlighted `TẢI HÀNG LOẠT (X VIDEO)` CTA button + `🛑 DỪNG TẢI` button.
- **Level 2 (Search & Filter Bar):** Real-time search input with clear button, styled select dropdowns for filtering (All, Video MP4, Photo Albums, >10k Likes, >100k Likes, >1 min) and sorting (Newest, Most Liked, Most Commented, Duration).

### E. Modern Video Grid Cards
- 9:16 aspect ratio preview cards with dark gradient overlay.
- Smart badges: Duration (Cyan), Album Note (Purple), Viral Star (Amber/Flame for >100k likes).
- Checkbox overlay with smooth hover state and easy toggle on click.
- Title and stats line (Heart icon + likes count, Chat icon + comment count).

### F. Result Flow & Quick Pipeline Handover
- Enhanced Single Video preview with resolution selection badges (1080p, 720p, MP3 Audio).
- Post-download pipeline buttons: `🎬 Nạp vào Biên Tập Phim`, `🎙️ Nạp vào Review Phim`, `📂 Mở Thư Mục`.

## 3. Implementation Details
- Files to modify:
  - `web/index.html`: Restructure Download tab layout, update CSS classes and modern HTML structure.
  - `web/style.css`: Add dedicated styles for `.download-segmented-tabs`, `.creator-showcase-card`, `.video-card-grid-modern`, `.download-toolbar-glass`, etc.
  - `web/app.js`: Ensure all element IDs and event bindings remain intact, enrich card rendering templates with new badge designs.

## 4. Verification & Testing
- Check responsive layout on various screen sizes.
- Verify Single Video download analysis and start.
- Verify Douyin Channel scan, search, filter, sort, select-all, and batch download.
- Verify compilation and zero console errors.
